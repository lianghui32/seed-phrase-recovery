# seed-phrase-recovery

BIP-39 助记词恢复工具：忘记或记错助记词中的**一个词**时，用已知的其余词 + 钱包地址，自动找回正确的那个。

典型场景：抄写时漏了一个词、某个词记不清是否写对、备份缺了一角。

## 原理

BIP-39 英文词表共 2048 个词。助记词（12/15/18/21/24 词）丢失其中 1 个时，候选组合最多只有 **2048 种**——普通电脑几秒到几分钟即可穷举完毕。

工具对每个候选组合：

1. 调用 BIP-39 校验和验证该组合是否为合法助记词（约半数会被校验和淘汰）
2. 按配置的 BIP-44 派生路径派生 EVM 地址（Ethereum / BSC / Polygon 等通用）
3. 与目标钱包地址比对，命中即输出完整助记词

地址派生基于 [ethers.js](https://ethers.org/)（经广泛审计的 BIP-32/BIP-39 实现），并通过官方测试向量 + 签名恢复闭环在 CI 中持续验证。

## 使用方法

```bash
git clone https://github.com/lianghui32/seed-phrase-recovery.git
cd seed-phrase-recovery
npm install
```

编辑 [index.js](index.js) 顶部的 `CONFIG`（只改这一处）：

```javascript
const CONFIG = {
  // 已知词，按原顺序填写，丢失的那个位置不填。
  // 12 词助记词 -> 填 11 个；15 词 -> 14 个；18 -> 17；21 -> 20；24 词 -> 填 23 个
  knownWords: ['word1', 'word2', /* ... */],

  // 目标钱包地址（EVM 链通用），大小写不敏感
  targetAddress: '0x你的钱包地址',

  // 派生路径（见下表）
  derivationPath: "m/44'/60'/0'/0/0",
};
```

运行：

```bash
node index.js
```

程序会对每个可能的缺失位置逐一枚举全部 2048 个候选词（带进度显示），找到与目标地址匹配的组合后打印完整助记词并退出；全部位置穷举无果时会给出排查建议。

## 派生路径怎么选

同一助记词在不同路径下派生出的地址不同，**必须与你钱包使用的路径一致**：

| 钱包 | 路径 |
|---|---|
| MetaMask / Trust / Ledger Live 等大多数 | `m/44'/60'/0'/0/0` |
| Ledger Legacy | `m/44'/60'/0'/0` |

不确定时先用默认值试；找不到可换 Legacy 路径，或把路径末位 `0` 改成 `1`、`2`（对应第 2、3 个账户）再试。

## 支持范围

| 场景 | 支持情况 |
|---|---|
| 12 / 15 / 18 / 21 / 24 词助记词缺失或记错 1 个词 | ✅ 完整支持（自动按已知词数量识别） |
| EVM 系地址（ETH、BSC、Polygon 等） | ✅ 路径可配置 |
| 自定义派生路径（含 Ledger Legacy、不同账户索引） | ✅ |
| 缺失 2 个及以上词 | ❌ 组合数指数级增长，不现实 |

## 安全提醒

- ⚠️ **仅用于恢复你自己的钱包**，用于他人钱包属违法行为
- 请在可信的离线设备上运行；恢复成功后立即将助记词转移到安全的离线备份
- 任何索要你助记词的"客服""恢复服务""工具"都是骗局——助记词 = 资产所有权
