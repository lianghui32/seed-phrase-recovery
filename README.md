# seed-phrase-recovery

BIP-39 助记词恢复工具：忘记或记错 **12 词助记词中的一个词**时，用已知的 11 个词 + 钱包地址，自动找回正确的那个。

典型场景：抄写时漏了一个词、某个词记不清是否写对、备份缺了一角。

## 原理

BIP-39 英文词表共 2048 个词。12 词助记词丢失其中 1 个时，候选组合最多只有 **2048 种**——普通电脑几秒到几分钟即可穷举完毕。

工具对每个候选组合：

1. 调用 BIP-39 校验和验证该组合是否为合法助记词（约半数会被校验和淘汰）
2. 按 BIP-44 路径 `m/44'/60'/0'/0/0` 派生 EVM 地址（Ethereum / BSC / Polygon 等 EVM 链通用）
3. 与目标钱包地址比对，命中即输出完整助记词

## 使用方法

```bash
git clone https://github.com/lianghui32/seed-phrase-recovery.git
cd seed-phrase-recovery
npm install
```

编辑 [index.js](index.js) 中的两处配置：

```javascript
// 已知的 11 个词（保持原顺序；丢失位置留空，程序会自动逐位插入候选词）
const knownWords = ['word1', 'word2', /* ...共 11 个 */];

// 目标钱包地址（用于验证哪个候选是正确的）
const targetAddress = '0x你的钱包地址';
```

运行：

```bash
node index.js
```

程序会对 11 个可能的缺失位置逐一枚举全部候选词，每个位置结束时输出进度；找到与目标地址匹配的组合后打印完整助记词并退出。

## 支持范围

| 场景 | 支持情况 |
|---|---|
| 12 词助记词缺失 / 记错 1 个词 | ✅ 完整支持 |
| EVM 系地址（ETH、BSC、Polygon 等） | ✅ `m/44'/60'/0'/0/0` |
| 24 词助记词 | ⚠️ 原理相同，但候选组合数大增，暂不内置 |
| 缺失 2 个及以上词 | ❌ 组合数指数级增长，不现实 |

## 安全提醒

- ⚠️ **仅用于恢复你自己的钱包**，用于他人钱包属违法行为
- 请在可信的离线设备上运行；恢复成功后立即将助记词转移到安全的离线备份
- 任何索要你助记词的"客服""恢复服务""工具"都是骗局——助记词 = 资产所有权
