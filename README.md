# 助记词恢复工具

## 项目简介

本项目是一个基于 Node.js 的工具，用于恢复以太坊钱包的12个助记词。通过已知的11个正确的助记词和目标钱包地址，程序将尝试匹配出正确的第12个助记词。

## 安装环境

### 前提条件

- **Node.js**：确保已安装 Node.js（推荐版本：14.x 或更高）。
- **npm**：Node.js 的包管理工具（通常会随 Node.js 一起安装）。

### 安装步骤

1. **克隆项目**：
   
   ```bash
   git clone https://github.com/your-repo-url.git
   cd your-repo-name
   ```

2. **安装依赖**：
   
   ```bash
   npm install
   ```

3. **安装额外库**：
   
   - 本项目依赖于 `ethers.js` 和 `bip39` 库。如果尚未安装，请运行以下命令：
     
     ```bash
     npm install ethers bip39
     ```

## 使用方法

### 修改配置

在代码中，你需要根据实际情况修改以下配置：

```javascript
// 正确的11个已知词（不含空位）
const knownWords = [
  'A', 'A', 'A', 'A', 'A', 'A', 'A', 'A', 'A', 'A', 'A'
];

const targetAddress = '0x4...........................8'; // 目标地址
```

- 将 `knownWords` 替换为实际的11个已知助记词。
- 将 `targetAddress` 替换为实际的目标钱包地址。

### 运行程序

在项目根目录下运行以下命令启动程序：

```bash
node index.js
```

程序将自动尝试所有可能的第12个助记词，并输出匹配到的目标地址。

## 注意事项

1. **助记词安全性**：
   
   - 助记词是钱包的敏感信息，请确保在安全的环境中运行本程序。
   - 不要在公共或不安全的设备上运行此程序。

2. **性能问题**：
   
   - 助记词的单词表通常包含2048个单词，程序需要尝试所有可能的组合。这可能需要一定的时间。
   - 如果目标地址不正确或已知的11个助记词有误，程序可能无法找到正确的结果，请自行求助AI。

3. **其他链的支持**：
   
   - 本代码默认支持以太坊链。如果需要支持其他区块链（如BSC、Polygon等），可能需要修改代码中的网络配置。

## 依赖库

- **ethers.js**：用于生成钱包地址。
- **bip39**：用于处理助记词。
